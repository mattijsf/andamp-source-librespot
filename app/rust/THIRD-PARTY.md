# Rust crates linked into the library

The crates compiled into `libandamp_librespot.so`, with the license each one declares in
its `Cargo.toml`. 223 crates; the two ABIs link the same set. Build scripts,
procedural macros and test-only dependencies are left out, because they run on the build
machine and are not in the library. The six `librespot-*` crates are built from the
submodule at `app/third_party/librespot`.

The table is generated by hand. In `app/rust`, with the submodule checked out:

```
cargo tree --locked --target aarch64-linux-android -e normal,no-proc-macro \
  --prefix none --format '{p}|{l}|{r}' | sed 's/ (\*)$//' | sort -u
```

Run it again with `--target x86_64-linux-android` to check the other ABI. Regenerate the
table when `Cargo.lock` or the librespot pin changes. `shannon` declares no repository, so
its row links to crates.io.
